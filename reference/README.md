# Reference Library

Load the smallest relevant reference for the current task. These files hold
discovery policy, source URLs, fetch recipes and historical research. They are
not run state and they do not authorize Git or database mutations.

| File | Read when |
|---|---|
| discovery.md | Before evaluating candidates or selecting search queries |
| links.md | At the start of every sweep, including its do-not-retry section |
| annual.md | Checking Ljubljana fixtures whose booking or event window is near |
| regions.md | Checking regional fixtures and the avto-moto calendar |
| artists.md | Before the named-artist concert pass |
| sources.md | A source needs more context than the URL index provides |

Dates marked verified describe the date of that research, not current validity.
Confirm the current year and fetch the event page before accepting a candidate.
Year-specific examples are evidence or query templates, never a fixed run clock.
Booking leads may be tracked before the event enters the horizon, but must not
be saved as active events outside that horizon.
